Recall is the safety number: of all planted runbook violations, what fraction did the automated gate catch? A miss is the costly error.

1 · How we built the test

A
Runbook-anchored gold set. Every case traces to a section of the internal IT runbook (EOL upgrade SLA, CVSS patch tiers, outage comms, password self-service, least-privilege access).
B
12 drafter cases run LIVE: they pull real EOL dates (endoflife.date), real CVSS scores (CIRCL), real service status (statuspage) at eval time — no mock.
C
14 critic cases = 6 known-good controls + 8 planted runbook violations: wrong CVSS SLA tier, invented EOL date, severity-without-lookup, setting a password, granting admin, inventing an outage + promising a restore time, answering the wrong question.

2 · How we verified

Gate
Deterministic confusion matrix. Each hand-labeled resolution goes to the real critic node; its verdict is compared to the ground-truth label. No LLM grading an LLM — this is the strongest proof of the automated gate.
Drafter
Independent Diamond judge (qwen3:30b on a separate node) refutes each live resolution per criterion (grounded / on-runbook / addresses), failing closed when unsure, plus deterministic grounding checks.
